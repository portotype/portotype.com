# Charts engine

Most Charts you and I can easily produce have been the same for the last 30 years. Bar Charts, Column Charts, Line charts, Area charts and Pie have been around for what looks like a million years.

But that's not enough. The world is moving into a) more information and related to that, also b) shorter attention spans. That means that we have the need for better visualizations, that are more compelling, easier to understand, funnier too.

We currently lack that visualization layer.

I propose the creation of a Charts library that uses the coolest available tech - particle physics, 3D, GPU rendering, to create the best Charts the world has even seen.
